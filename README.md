# Proyecto de Gimnasio

**Autor:** Jesús Manuel Sánchez Alfonso
**Tema:** Sistema para un Gimnasio

*¿Qué espero aprender?*
Espero fortalecer mis conocimientos en el desarrollo de aplicaciones web y móviles, dominar buenas prácticas de control de versiones con Git, y poder aplicar mis habilidades de programación para construir un sistema funcional desde el inicio a fin.

 **proyecto con Docker**

Este proyecto está empaquetado con Docker para facilitar su ejecución sin necesidad de configurar Node.js o PostgreSQL de forma local.

**Requisitos:**
 Tener [Docker Desktop](https://www.docker.com/products/docker-desktop/) instalado y ejecutándose.

**Instrucción:**
 Abre una terminal en la raíz de este proyecto.
 Ejecuta el siguiente comando para construir y levantar los contenedores (servidor y base de datos):
   ```bash
   docker compose up
   ```
